# Satellitt-og-Objekts-gjenkjennings-prosjekt-
Prosjektet til meg(Sigurd) og Mattias.  Vi skal lage en antenne får å laste ned data fra satellitter og bygge et nevralt nettverk for å gjenkjenne og oppdage skip fra satellitt bilder

## Planlegging

Se [forslag til prosjektplan](PLAN.md) for mål, datasett, modeller, utstyr og fremdrift. Prosjektet er foreløpig i planleggingsfasen.

## Oppstart for objektdeteksjon

Sigurd arbeider videre med skipsdeteksjon på HRSID som et selvstendig spor. Se [oppsummering og oppstart](OPPSTART.md) for Python-miljø, filstruktur, YOLO/COCO og lisensinformasjon.

## Hovedformål: lære ved å gjøre selv

Sigurd skriver prosjektkoden selv og velger egen struktur. Veiledningen skal forklare begreper og kommandoer, gi én liten oppgave om gangen og vente på eget forsøk før neste steg. Et ferdig produkt er sekundært til forståelse. Se [lærings- og arbeidsreglene](AGENTS.md), som gjelder foran eldre arbeidsforslag.
